# CM27 LIVE DATABASE

Repositorio de datos públicos para CLUB MASTER 27. No contiene partidas guardadas.

## Archivos
- `manifest.json`: versión, compatibilidad e integridad.
- `database.json`: snapshot inicial de clubes y jugadores.
- `changelog.json`: historial de cambios.

## Estado inicial
La versión 0.1.0 es una exportación inicial de la base incluida en CLUB MASTER 27 3.5.2. Conserva los estados de verificación originales. No debe interpretarse como una plantilla completamente verificada. Los perfiles `game_profile` son estimaciones del juego.

## Seguridad
Nunca subir partidas guardadas, tokens, contraseñas ni datos privados.
